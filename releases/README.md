# Umami Analytics Mobile Releases

Builds oficiais compilados do aplicativo Android para Umami Analytics Cloud.

## 📦 Versões Disponíveis

### v1.1 — Umami Mobile Release Oficial
- **Arquivo**: [`umami-analytics-v1.1.apk`](./umami-analytics-v1.1.apk)
- **Tamanho**: ~13 MB
- **Assinatura**: Assinado com `umamikey` (APK Signature Scheme v2)
- **Target SDK**: Android 15 (API 35) / Min SDK: Android 7.0 (API 24)
- **Download Direto Web**: `https://umami-chi-topaz.vercel.app/downloads/umami-analytics-v1.1.apk`

### 📱 Recursos Nativos
- Suporte nativo à plataforma Cloud com autenticação persistente (10 anos).
- Aceleração por hardware para WebGL Shaders e tema MCP OS.
- Layout Imersivo AMOLED sem barras de navegador.
- Suporte a recarregamento por gesto (*Pull-to-refresh*).
